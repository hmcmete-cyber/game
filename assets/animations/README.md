**In Studio Play they already work without publishing**: the game builds them from
`Shared/AnimationData.luau`. A live Roblox server can't do that, so publish them
before releasing the game.

## Publish (once per file)
1. Studio → **File → Import...** isn't needed: just drag `NpcIdle.rbxmx` from Windows Explorer
   into the Studio viewport (or right-click **Workspace → Insert from File...** and pick it).
   A `KeyframeSequence` named `NpcIdle` appears in Workspace.
2. Right-click it → **Save to Roblox...** (publish as Animation). Choose the same owner
   as the game (your account, or the group if the game belongs to a group) — otherwise
   the animation will not play in the game.
3. Copy the asset id from the dialog / Creator Dashboard.
4. Paste it into `src/shared/Animations.luau`, e.g. `NpcIdle = "rbxassetid://1234567890",`
5. Delete the `KeyframeSequence` from Workspace. Repeat for every file.

Optional check: Avatar → **Rig Builder** → R15 Block Rig, open **Animation Editor**, select the
rig, `...` → Import → From Roblox / or put the KeyframeSequence in `Rig/AnimSaves` and Load it.

Real mocap from rigdirectors.com can replace any file later: publish it and put its id in
`Animations.luau` under the same name — no code change needed.
